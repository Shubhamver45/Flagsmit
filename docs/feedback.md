# Early Feedback Questions

Copy and paste these three questions into a GitHub Issue or Discussion when trying Flagsmith Guardian:

1. **What did you run it against?** (Self-hosted Flagsmith version, Docker Compose / Kubernetes / bare Python, Prometheus or push metrics?)
2. **What broke or felt confusing?** (Any setup step, `guardian init` prompt, webhook configuration, or guardrail behavior that didn't work as expected?)
3. **What is missing for your workflow?** (Metric sources, notification channels, approval flows, or deployment manifests?)
