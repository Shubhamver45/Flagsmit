# Deploying Guardian for Free

Guardian is distributed as a public, non-root Docker image (`ghcr.io/shubhamver45/flagsmith-guardian:latest`) so anyone can deploy it against their Flagsmith instance.

---

## Option A: Render Free Tier (Fastest — Public HTTPS URL, Zero Server Setup)

Render provides a free Docker web service using [`render.yaml`](../render.yaml) with automatic HTTPS (`https://flagsmith-guardian.onrender.com`).

1. Sign in to [Render](https://render.com/) with GitHub.
2. Click **New + → Blueprint** and select **`Shubhamver45/flagsmith-guardian`**.
3. Fill in the prompted Flagsmith variables (`FLAGSMITH_URL`, `FLAGSMITH_ADMIN_API_KEY`, `FLAGSMITH_ENVIRONMENT_KEY`, and optionally `SLACK_WEBHOOK_URL`). `GUARDIAN_API_TOKEN` and `FLAGSMITH_WEBHOOK_SECRET` are auto-generated by Render.
4. Click **Apply** — Render builds the Dockerfile, runs `/health`, and exposes your public HTTPS URL.

> [!NOTE]
> Render's free tier spins down after 15 minutes of inactivity and uses ephemeral container storage. For 24/7 uptime and persistent SQLite state, use **Option B** on a free Linux VM.

---

## Option B: Free Linux VM (Oracle Cloud Always Free / AWS EC2 Free Tier)

1. Provision an Ubuntu/Debian VM (e.g., Oracle Cloud Always Free ARM VM or AWS EC2) with ports **80** and **443** open.
2. Install Docker & Docker Compose, then clone the repository:
   ```bash
   git clone https://github.com/Shubhamver45/flagsmith-guardian.git
   cd flagsmith-guardian
   cp .env.example .env
   cp config.example.yaml config.yaml
   ```
3. Edit `.env` and set:
   - `GUARDIAN_ENV=production`
   - `GUARDIAN_API_TOKEN` (`python3 -c "import secrets; print(secrets.token_urlsafe(32))"`)
   - `FLAGSMITH_WEBHOOK_SECRET` (`python3 -c "import secrets; print(secrets.token_hex(32))"`)
   - `FLAGSMITH_URL`, `FLAGSMITH_ADMIN_API_KEY`, `FLAGSMITH_ENVIRONMENT_KEY`
   - `GUARDIAN_DOMAIN=guardian.yourdomain.com` (for automatic Let's Encrypt HTTPS via Caddy)
4. Start Guardian + Caddy:
   ```bash
   docker compose -f docker-compose.prod.yml up -d
   ```
5. Point your Flagsmith environment webhook to `https://guardian.yourdomain.com/webhooks/flagsmith` using the same `FLAGSMITH_WEBHOOK_SECRET`.
